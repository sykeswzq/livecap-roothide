
## LiveCap v2.0.0 CI Build 失败根因分析与修复

### 时间线
- 13:44: 开始诊断 CI Build 持续失败问题（v1.0.100 ✅ → v2.0.0 ❌）
- 13:46: 定位根因并推送修复 commit `0f7bcac`

### 根因
PrefBundle 编译缺少 `-framework CoreFoundation`

**调用链**：
```
v2.0.0 重构
  ↓
LiveCapPrefs.m 新增 LCSetPref() 使用 CFPreferencesSetAppValue / CFPreferencesAppSynchronize
  ↓
build.sh 编译 PrefBundle 时只有 Foundation/UIKit/CoreGraphics
  ↓
缺失 CoreFoundation framework → undefined symbol 链接错误
  ↓
CI Build 步骤在 ~6 秒内快速失败
```

### 修复
文件：`build.sh` 第 52 行
```bash
# 修改前
-framework Foundation -framework UIKit -framework CoreGraphics \

# 修改后
-framework CoreFoundation -framework Foundation -framework UIKit -framework CoreGraphics \
```
